# Programación 1
Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.
## Programas incluidos
### Calculadora IMC - PseInt
El programa evalúa la edad del usuario, en caso de tener la edad mínima requerida, se calculará su IMC y se le dará a conocer al usuario su índice junto a su categoría correspondiente.
### Operación Rescate - PseInt
Programa para calcular y clasificar las posibilidades de cada estudiante de obtener promedios sobresalintes, regulares, suficientes o reprobatorios, según resultados de 3 exámenes anteriores y uno más aún sin evaluar.
### Generador de CURP - PseInt
Genera los primeros 16 dígitos de la CURP de una persona a partir de sus datos ingresados.
### Figuras en Terminal - Python
Imprime en la terminal las figuras que elija el usuario (Reloj de arena, Rombo, Moño, Copa, y todos los anteriores) de NxN de dimensión, siendo N un número que ingresa el usuario.
### BlackJack - Python
Simulación del juego BlackJack o 21, implementando una interfaz gráfica con Tkinter. (SIN APUESTAS)
### Función de Contraseña Segura - Python
Función que verifica si la contraseña recibida es segura o no.

## Ejecución de un programa

### Figuras en Terminal - Python
